---
title: "Use on Mobile"
description: "Install YukiCares as an app on your phone or desktop for quick, app-like access — it works as a Progressive Web App."
---

YukiCares is a **Progressive Web App (PWA)** — you can install it to your home screen or desktop and use it like a native app, with a mobile-friendly layout and a bottom navigation bar.

## Install on Android / Chrome

<Steps>
  <Step title="Open your school workspace">
    Visit `your-school.yukicares.cloud` in Chrome.
  </Step>
  <Step title="Tap the install prompt">
    An **Install YukiCares** banner appears — tap it. (Or use the browser menu → **Install app / Add to Home screen**.)
  </Step>
</Steps>

## Install on iPhone / iPad (Safari)

<Steps>
  <Step title="Open in Safari">
    Visit your workspace in Safari.
  </Step>
  <Step title="Share → Add to Home Screen">
    Tap the **Share** icon, then **Add to Home Screen**.
  </Step>
</Steps>

## Install on desktop

In Chrome or Edge, click the **install icon** in the address bar (or menu → **Install YukiCares**).

## Why install it?

<CardGroup cols={2}>
  <Card title="App-like experience" icon="mobile-screen">
    Full-screen, with a mobile bottom-tab layout for one-handed use.
  </Card>
  <Card title="Push notifications" icon="bell">
    Get alerts on your device — enable them in [Notifications](/settings/notifications).
  </Card>
  <Card title="Fast loading" icon="bolt">
    The app shell is cached, so it opens quickly.
  </Card>
  <Card title="Home-screen icon" icon="star">
    Launch straight from your home screen or dock.
  </Card>
</CardGroup>

<Note>
You still sign in as usual, and all data stays live from your school's secure workspace.
</Note>
