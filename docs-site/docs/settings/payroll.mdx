Payroll settings control the **statutory deductions** applied when you generate a salary payout.

<Steps>
  <Step title="Open Settings → Payroll">
    Review the current rates.
  </Step>
  <Step title="Set your rates">
    - **PF (Provident Fund)** rate and wage ceiling
    - **ESI (Employee State Insurance)** rate and wage threshold
    - **Professional tax** (flat)
  </Step>
  <Step title="Save">
    These rates are used automatically when you run a payout.
  </Step>
</Steps>
![payroll image](/img/payroll.png)
## How deductions are calculated

When you process a salary payout:

- **Gross** = basic + allowances + bonus
- **PF** = PF rate × min(basic, PF wage ceiling)
- **ESI** = ESI rate × gross, while gross is at or below the ESI threshold (otherwise 0)
- **Professional tax** = the flat amount you set
- **Net pay** = gross − (PF + ESI + TDS + professional tax + other deductions)

<Tip>
You can **override** any statutory component on an individual payroll run if a special case applies.
</Tip>

<Note>
If you leave these blank, YukiCares falls back to sensible defaults. Confirm them before your first payroll run — see [Teacher Payouts](/staff/payouts).
</Note>
