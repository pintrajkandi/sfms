## Fee reminders

YukiCares can automatically remind guardians about upcoming and overdue fees over **WhatsApp / SMS**, in staged waves (before due, on due, and after overdue).

<Steps>
  <Step title="Open Settings → Notifications">
    Configure how and when reminders go out.
  </Step>
  <Step title="Enable reminders">
    Turn on the reminder schedule. Each stage has its own guard so parents aren't messaged repeatedly for the same stage.
  </Step>
</Steps>

<Info>
Reminders run on a daily schedule in the background. When an invoice reaches a reminder stage (e.g. 3 days before due), the guardian is messaged once for that stage.
</Info>

## Push notifications

Install YukiCares as an app (see [Use on mobile](/mobile-app)) and enable **push notifications** to get alerts on your device — for example when a payout needs action.

<Steps>
  <Step title="Open Settings → Notifications">
    Find the push toggle.
  </Step>
  <Step title="Allow notifications">
    Your browser/device will ask for permission — accept it to receive alerts.
  </Step>
</Steps>
![notifications images](/img/notifications.png)
<Note>
YukiCares only logs and messages the information needed for the reminder (amounts, invoice numbers). It never sends card or payment credentials.
</Note>
