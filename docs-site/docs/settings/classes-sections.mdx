---
title: "Classes & Sections"
description: "Define the classes and sections your school runs — they power the student, fee and reporting screens."
---

Classes and sections are the backbone of enrolment and reporting. Set them up before adding students.

<Steps>
  <Step title="Open Settings → Classes & Sections">
    You'll see the list of classes you've created.
  </Step>
  <Step title="Add a class">
    Enter a class name (e.g. *Class 1*, *Grade 10*, *Nursery*). You can control display order so classes list naturally.
  </Step>
  <Step title="Add sections to a class">
    For each class, add its sections (e.g. *A*, *B*, *C*). Section names are unique within a class.
  </Step>
  <Step title="Save">
    Your classes now appear as dropdown choices when adding or editing students.
  </Step>
</Steps>
![classes-sections image](/img/classes-sections.png)

<Tip>
Add every class you run up front. When you enrol a student, you'll pick the **class** and then its **section** from these lists.
</Tip>

<Note>
Renaming or removing a class doesn't change students already assigned to it — update those students individually if needed.
</Note>
