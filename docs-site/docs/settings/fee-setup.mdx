Fee types are the building blocks of billing. Create them once, then reuse them on every invoice and collection.

## Fee categories & types

<Steps>
  <Step title="Open Settings → Fee Setup">
    You'll see your fee categories and the fee types under them.
  </Step>
  <Step title="Create a fee type">
    Give it a **name** (e.g. *Tuition*, *Transport*, *Lab*, *Library*, *Sports*, *Exam*, *Activities*), assign a **category**, and optionally a **default amount**.
  </Step>
  <Step title="Save">
    The fee type is now selectable in the [Fee Collection wizard](/fees/collect-fee) and on invoices.
  </Step>
</Steps>

<Tip>
Set a **default amount** on common fee types so they auto-fill during collection — you can still override per student.
</Tip>

## Fee types vs. a student's assigned fees

There are two related concepts:

<CardGroup cols={2}>
  <Card title="Fee types (here)" icon="tags">
    The catalogue of billable items shared across the school. Used to build invoices.
  </Card>
  <Card title="Student fee structure" icon="user-graduate" href="/students/add-student">
    The annual amounts assigned to an **individual student** (school, tuition, transport, other). Drives their paid-vs-outstanding.
  </Card>
</CardGroup>
![fee-setup image](/img/fee-setup.png)
<Note>
Use **fee types** to itemise what you charge, and a **student's fee structure** to record how much that student owes for the year. See [Add a student](/students/add-student).
</Note>
