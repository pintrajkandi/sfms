Open **Teachers** from the sidebar to see all teaching staff.

<CardGroup cols={2}>
  <Card title="Search" icon="magnifying-glass">
    Find a teacher by name, employee ID, email, phone or department.
  </Card>
  <Card title="At a glance" icon="table">
    Employee ID, name, department, contact, base salary and status.
  </Card>
</CardGroup>

## Edit a teacher

Click any row (or **Edit**) to open the teacher's record and update their details, class assignments, salary structure or bank account. The same validation applies as on [Add Teacher](/staff/add-teacher).

<Tip>
Use **+ Add Teacher** on this page to register a new teacher without leaving the list.
</Tip>
