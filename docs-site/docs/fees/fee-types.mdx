Fee types are managed under [Settings → Fee Setup](/settings/fee-setup). This page explains how they're used day to day.

## Where fee types appear

<CardGroup cols={2}>
  <Card title="Fee Collection wizard" icon="wand-magic-sparkles" href="/fees/collect-fee">
    Pick one or more fee types and enter the amount for each.
  </Card>
  <Card title="Invoices" icon="file-invoice" href="/fees/invoices-receipts">
    Each fee type becomes a line item with quantity and price.
  </Card>
</CardGroup>

## Tips

<AccordionGroup>
  <Accordion title="Set default amounts">
    Give frequently-billed fee types a default amount so they auto-fill during collection. You can override per student.
  </Accordion>
  <Accordion title="Group with categories">
    Categories (e.g. *Academic*, *Facilities*) keep reports and breakdowns tidy.
  </Accordion>
  <Accordion title="Keep names clear">
    Use names parents will recognise on a receipt — *Tuition*, *Transport*, *Exam*, etc.
  </Accordion>
</AccordionGroup>
